# 🛡️ Full-Stack RPG Backend

A modular backend service built for a web-based RPG project, designed for seamless cross-platform synchronization between Windows and Arch Linux development environments.

## 🚀 Tech Stack
- **Runtime:** Node.js (v24+)
- **Framework:** Express.js
- **Database & ODM:** MongoDB Atlas & Mongoose
- **Version Control:** Git & GitHub

## ⚙️ Getting Started & Setup

To run this project locally on a new machine (e.g., setting up on Arch Linux):

1. **Clone the repository:**
   git clone https://github.com/DeniCastro/RPG-character-card-and-stats.git
   cd RPG-character-card-and-stats

2. **Install dependencies:**
   npm install

3. **Set up environment variables:**
   Create a .env file in the root directory and add your configuration:
   PORT=5000
   MONGO_URI=your_mongodb_connection_string_here

4. **Run the development server:**
   npm run dev
